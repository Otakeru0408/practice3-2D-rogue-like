# Rogue Like Game



### 操作方法

**移動**

キャラクターを中心にマウスの左クリックをした方向へ向かってキャラが進む。

クリックを離すと止まる。

このゲームはマウスのみで操作可能。



**ダッシュ**

左クリックをおした状態で同時に右クリックを押すと移動速度が速くなってダッシュ！

キャラクターの下にあるゲージはダッシュゲージでありHPではありません。



**透明化**

画面にある「Invisible!」ボタンを押すと透明になり、一時的に敵の攻撃がすり抜ける。

なんどでもつかえる。



### 目標

このゲームの目標は、マップに散らばっている10個の宝を収集して脱出すること。

全てを集めなくともゴールのドアがあれば入ることができるが、スコアは低くなる。

10個の宝をすべて集めよう！



### 特筆すべき点

・自動生成のダンジョン

BSPアルゴリズムを用いてダンジョンを自動生成しています。

・操作の簡便性

マウスのみの操作にすることで単純かつ分かりやすい操作性にしています。

・細かなアニメーション

ゲーム開始時のカウントダウンやRetry時のボタンの挙動など細かな点までこだわって作りました。



自動生成のダンジョンの当たり判定がとてもむずかしかったです :(
